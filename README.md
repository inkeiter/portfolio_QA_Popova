# 🧪 Портфолио QA Engineer

Добро пожаловать в мое портфолио, созданное в процессе обучения на курсе **QA Engineer** в [Нетологии](https://netology.ru/). Здесь вы найдете примеры моих практических работ и освоенных навыков в области обеспечения качества программного обеспечения.

## 📌 О курсе

Курс включал в себя изучение теоретических основ тестирования, а также практические задания, направленные на отработку навыков, необходимых в работе тестировщика.

В рамках обучения были охвачены следующие темы:

- Основы тестирования и виды тестирования
- Работа с баг-трекинговыми системами
- Использование DevTools и Postman
- Практика написания тест-кейсов и чек-листов
- Основы SQL
- Контроль версий с использованием **Git** и **GitHub**

## 🛠 Освоенные инструменты

В процессе работы над проектами были получены следующие практические навыки:

### 🔧 Git

- Инициализация и настройка репозиториев
- Работа с ветками, коммитами, слиянием (merge)
- Разрешение конфликтов
- Использование `.gitignore`
- Ведение истории изменений

### ☁️ GitHub

- Создание и клонирование репозиториев
- Работа с удалёнными ветками
- Pull-запросы и ревью кода
- Публикация проекта через **GitHub Pages**
- Размещение документации в формате Markdown
